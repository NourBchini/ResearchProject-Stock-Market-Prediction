# experiments/ — Preliminary Work (Not in the Revised Paper)

Everything in this directory is preserved for transparency and reproducibility
of the **preliminary** investigation. None of these files are required to
reproduce the revised paper; that pipeline lives in `analysis/` and `training/`
at the repo root.

The code here is unchanged from the original preliminary run except for two
adjustments:

1. Data paths in scripts that read `data/SPY.csv` were updated so they still
   resolve from this new location.
2. A short header was added to each script clarifying that it belongs to the
   preliminary pipeline.

## Why these are not in the revised paper

- **Hybrid model.** The mix-and-match design (CNN-LSTM for OHCV + Simple LSTM
  for Low) was a preliminary heuristic that introduced extra moving parts but
  did not beat the persistence baseline once the test-set peeking bug was
  corrected. The revised paper compares clean architectures only.
- **Feature engineering (steps 05, 06).** RSI / MACD / multi-asset features
  were a feasibility exploration. The revised paper sticks to raw OHLCV to
  keep the feature space interpretable.
- **Steps 02, 07_08, 12.** These were narrative / aggregation utilities for
  the preliminary write-up.
- **LinkedIn infographic.** Marketing asset only.

## Reproducing the preliminary pipeline

The preliminary scripts assume execution from their own directory:

```bash
cd experiments/preliminary_analyses
python 02_hyperparameter_table.py
python 05_volatility_features.py
python 06_market_wide_features.py
# … etc.
```

Some scripts in `run_all_analyses.py` reference step numbers (01, 03, 04, 09,
10, 11) that were promoted into `analysis/` because the revised paper still
uses them.
